Vision-and-Language Navigation (VLN) 作为具身智能（Embodied AI）的核心任务之一，正经历从传统仿真环境向真实物理世界跨越的范式转变。随着多模态大模型（VLM/VLA）的爆发，基于大模型的导航算法迭代日新月异，层出不穷的 arXiv 论文与顶会工作给研究者带来了严重的“信息过载”。

在实际的科研与工程探索中，我们发现一个显著的痛点：**许多工作在基准测试（Benchmark）上取得了 SOTA，但往往缺乏对真实物理世界部署（Sim2Real）的考量。** 对于试图复现算法、对比模型架构或寻找落地指导的开发者而言，核心的工程细节（如真机平台、底座模型、计算开销）往往散落在论文的 Appendix 中，导致极高的信息检索成本。

为此，我构建并维护了这个**VLN 算法全景梳理仓库**。本项目旨在以结构化的方式，持续追踪并记录该领域的最新进展与经典工作。
